## 📌 Sobre o projeto

O **Notícia360** é um protótipo navegável de um portal de notícias, desenvolvido como continuação da atividade vivencial anterior.

O projeto simula a experiência de explorar notícias, navegar por editorias e contratar uma assinatura Premium. Foi criado com finalidade **exclusivamente acadêmica**: os conteúdos jornalísticos, valores e meios de pagamento são fictícios.

> **Importante:** o arquivo `index.html` representa um protótipo interativo, e não um site de produção.

## 🖥️ Telas do protótipo

O protótipo possui **7 telas navegáveis**:

| Nº | Tela | Funcionalidades demonstradas |
|:--:|---|---|
| 01 | **Inicial** | Manchete principal e acesso às notícias |
| 02 | **Tecnologia** | Editoria, listagem de matérias e filtros |
| 03 | **Notícia** | Leitura, compartilhamento e salvamento |
| 04 | **Planos Premium** | Comparação e escolha entre planos mensal e anual |
| 05 | **Cadastro** | Formulário de registro demonstrativo |
| 06 | **Checkout** | Simulação de pagamento por cartão ou Pix |
| 07 | **Créditos** | Identificação dos responsáveis pelo projeto |

## 🧭 Como navegar

1. Abra o arquivo **`index.html`** em um navegador (Chrome, Edge ou Firefox), ou acesse a versão publicada no GitHub Pages.
2. Clique na manchete principal ou entre na editoria **Tecnologia**.
3. Abra uma notícia e escolha **Conhecer os planos**.
4. Selecione o plano **Mensal** ou **Anual**.
5. Preencha o cadastro com **dados fictícios** ou utilize o modo de demonstração.
6. Escolha **Cartão** ou **Pix** e clique em **Confirmar assinatura** para concluir a simulação.
7. Acesse **Créditos** pelo menu superior ou pelo rodapé.

**Aviso de segurança:** não utilize dados reais de pagamento. A experiência de compra é apenas demonstrativa.

## 🚀 Publicação no GitHub Pages

Para disponibilizar o protótipo por um link público:

1. Envie o arquivo **`index.html`** e a pasta **`assets/`** para a raiz do repositório.
2. Abra **Settings → Pages** no GitHub.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch **`main`** e a pasta **`/(root)`**.
5. Clique em **Save** e, após a publicação, abra o endereço disponibilizado pelo GitHub Pages.
